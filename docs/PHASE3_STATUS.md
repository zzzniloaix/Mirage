# Phase 3 status

Phase 3 of the VMAF work order is its §3, the unified event timeline, on the branch `vmaf/phase-3`, made from `vmaf/phase-2` while Phase 2's PR waited (`docs/DECISIONS.md` D-066); the owner merged Phase 2 into `main` on 2026-11-02 (PR #4), and `main` was merged into this branch then. This file says, for each item of §3, what is done, where its records are, and what remains. Every number comes from a committed record named next to it; where there is none, it says MEASUREMENT PENDING. Every item is surveyed and designed. Round 1's questions of `docs/PHASE3_DECISIONS_PENDING.md` were answered on 2026-11-02 (D-071 to D-081), and round 1's packages are built: the shared declarations (WP00a), the timeline's model, axis and overlap query (WP01), drop detection (WP02), the JSON and ladder report readers (WP03), playlist events and cue pairing (WP04), the demux pass (WP06), the synthetic ladders (WP10), the timeline document and its JSON Schema file (WP08, then WP08b and WP08c with the owner's answers to the questions building it raised, D-092, D-099 and D-100), the timeline build and `mirage_vmaf`'s `timeline` and `attribute` subcommands (WP09a), and §3.2's two acceptance tests (WP11a), which pass (below, "Round 1's packages").
